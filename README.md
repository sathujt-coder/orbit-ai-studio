# ORBIT AI Studio

Autonomous Software Studio — a multi-agent software-development workspace with independent reviews and human approval.

This repository is being initialized for the ORBIT AI Studio v0.4 Coding Factory implementation. Source code is proposed in a separate development branch and must pass CI and review before merge.

- Planned scope: 12 departments, 24 AI agents, an interactive 3D workspace, review gates, coding workflows and GitHub integration.
- Safety: no autonomous publishing, merging or production deployment without explicit human approval.
