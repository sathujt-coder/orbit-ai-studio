# ORBIT — Web Delivery Checklist

## 1. Product discovery
- [ ] PO-A/B define independent Web vision and measurable goals
- [ ] Research-A/B investigate users and competitors
- [ ] BA-A/B produce user stories and acceptance criteria
- [ ] PM-A/B plan milestones and risk register
- [ ] Record independent cross-review and human approval

## 2. Web design and architecture
- [ ] UX-A/B design responsive Web user journeys and accessibility
- [ ] Tech Lead-A/B design APIs, data model, permissions and architecture
- [ ] Independently review design and architecture

## 3. Web implementation
- [ ] DEV-A and DEV-B implement independently in isolated workspaces
- [ ] Reciprocal code review and Tech Lead arbitration
- [ ] Build real frontend, backend, database and authentication
- [ ] Open PR with traceable test and review evidence

## 4. Quality and security
- [ ] QA-A/B execute unit, integration and browser E2E tests
- [ ] QC-A/B verify defects, regression and release gates
- [ ] Security-A/B check secrets, dependencies, authorization and threats
- [ ] DevOps-A/B verify staging, monitoring, backups and rollback
- [ ] Test accessibility, browser compatibility and performance

## 5. Web acceptance and release
- [ ] UAT on staging against signed requirements
- [ ] Resolve all release blockers and rerun regression
- [ ] Obtain explicit written human acceptance
- [ ] Human-approved production deployment and smoke tests
- [ ] Observe live stability, analytics and marketing outcomes

## 6. Mobile — deferred
- [ ] Confirm signed Web acceptance
- [ ] Start separate Flutter/Android/iOS roadmap
- [ ] Reuse proven APIs and user journeys

No mobile development before Web acceptance. CI green or simulated agent approvals are not acceptance.
