# Studio Generator — role-based production line
Development-only UI refactor after P6.2j.1. The overview prioritizes twelve role stations in backend order, grouped into four visual segments. Each station shows actual legacy stage status, A/B responsibilities, expected deliverable, recent artifact/review counts, approval requirement and intended handoff. The preceding stage status is a visual indicator, not a dependency or execution authorization. No individual agent live status is inferred. PRD, planning and coding are separate workflows linked explicitly; no claim that legacy stage completion means their acceptance. Existing pipeline controls, inspector, 3D office, coding and GitHub delivery remain available. Project switching clears the old line, failed polling marks displayed data stale. No changes to backend, models, prompts, budgets, gates, permissions or production release policy. Tests cover status mapping, order, selection, links, project switch and responsive layout. P6.3 implementation remains deferred until this UI checkpoint is checked.
