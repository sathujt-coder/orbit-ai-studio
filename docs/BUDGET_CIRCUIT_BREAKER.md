# P5.7 Budget & Circuit Breaker
All server tracked inference paths (pipeline, coding, chat, provider probe) use shared durable guard after concurrency/resource admission, before token/cost start. Trusted standalone CLI can bypass unless it explicitly injects guard. Demo and metadata endpoints are not inference. ORBIT_BUDGET_MODE=observe default preserves existing advisory project budgets, logs reservation warnings; enforce refuses unknown rates and prospective over-budget requests. Existing owner monthly project USD budget becomes an admission cap in enforce mode. Operator environment ORBIT_MONTHLY_GLOBAL_USD and ORBIT_MONTHLY_AGENT_USD optional decimal strings (empty unlimited, zero permits known zero API fee). Agent cap aggregates exact agent ID across projects. ORBIT_MONTHLY_{GLOBAL,PROJECT,AGENT}_TOKENS integer, zero unlimited. ORBIT_MAX_RUN_CALLS=64 enforced in both modes for non-null run IDs, includes failed attempts and format retries; new run or manual retry has new run ID. System probe receives run ID. No automatic replay.

Atomic transaction checks current UTC month, recorded actual costs/tokens plus conservative pending/unknown holds, and reserves configured context window plus explicit max output tokens using current exact rate. Immutable cost snapshot in same DB transaction. Unknown history without reservation blocks relevant enforce cap, known local zero API fee remains zero. Unknown usage after request retains estimated reservation, including failures; no silent release or auto reconciliation. Actual complete provider usage replaces reservation, overrun recorded. Billing periods attributed to request start; old-month unresolved holds are not counted in new month. Not a provider hard billing ceiling: configured context/output limits and price estimates may differ from billed tokens, remote context not enforced by transport, other billing categories excluded. Zero cost local is assumption as before. Monthly queries scan ledger; scaling optimization later. No claim of avoiding all spend.

Persistent circuit keyed by exact provider/endpoint/model. ORBIT_BREAKER_FAILURES=3 and ORBIT_BREAKER_COOLDOWN=60 seconds configurable. Consecutive provider_error/internal_error opens circuit; output_error is a response, not transport outage. Cooldown followed by one real demand-driven half-open request, no automatic probe or cross-model fallback; success closes, failure reopens. Generation epochs discard stale completions; startup recovery of uncertain half-open reopens, leaves usage pending. Same exact model across separate credentials shares breaker; aliases may not. Stop/resume CAS operator action persists; prevents new admissions, not already admitted/in-flight calls. Queued tasks deferred while stopped; demo unaffected. Running pipeline/coding refused at next inference boundary follows existing failure/quality gates. No auto cancel or refund.

GET /api/provider/protection, POST /api/provider/protection/stop operator-only and CSRF protected; GET /api/projects/{id}/protection member scoped. /protection.html operator shows budget policy, accounted/reserved totals, unknown/overruns, breakers and latest denials; stop/resume explicit confirmation. Policy startup config not editable from browser; existing project budget owner form remains. Real HTTP fixture tests circuit behavior; real offline test zero-dollar policy, run cap and stop/resume, two real local model calls. GPU/production/paid API not tested.

Dispatcher checks persistent emergency stop before claim; no attempt or history churn while stopped. If stop races with a claim, requeue before execution without consuming the attempt counter. Observe-mode warning count is exposed in budget view. Added concurrent reservation test with two actual threads sharing SQLite and a blocked provider fixture, and subprocess queue preservation test. Project budget is an admission estimate, not a billing guarantee.
