P3.4 local HTTP endpoints POST /api/auth/login, GET /api/auth/session, POST /api/auth/logout. Login/logout require explicit local Origin and X-ORBIT-UI, logout also X-ORBIT-CSRF. HttpOnly SameSite=Strict cookie scoped to /api; no Secure flag because localhost HTTP only. Provision user via python tools/create_auth_user.py --user alice. Global throttle after ten failed logins per minute; local-only, not production-grade. Auth endpoint unit tests exercise handler functions, not actual HTTP. Existing business APIs remain unauthenticated until P3.6; do not expose publicly. No UI yet.
