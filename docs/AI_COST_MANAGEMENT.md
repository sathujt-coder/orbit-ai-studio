# P5.2 — AI Cost Management
Open /cost.html. Project members read their own project estimate; owners set an advisory monthly UTC budget; deployment operator (ORBIT_PROVIDER_ADMINS) manages rate versions and all-project reporting. Rates are manual USD per million input/output token decimal strings, up to six fractional digits. No provider API billing calls or pricing scraping. A rate binds the exact provider, approved endpoint fingerprint and model. Updating/disabling creates an immutable version and affects only future attempts; old P5.1 records without a basis are explicitly unpriced historical records. Each usage transaction snapshots its rate before outbound inference. Disabled rate overrides local defaults. No reprice of historical calls. Money uses integer picodollars and exact Python integer aggregation, JSON decimal strings. Complete provider counts are required for priced estimates, even on failed output; pending/incomplete/inconsistent counts remain unknown. Known subtotals exclude unknown calls. Local loopback Ollama without credential and without cloud tag defaults to assumed zero API fee, not independently verified invoice; other endpoints need explicit rates, including remote Ollama and compatible local gateways. Excludes hardware, power, tax, cache tiers, discounts, non-token billing and currency conversion. Budget alerts use current UTC calendar month, 80% threshold and known spend; missing data remains visible, no hard enforcement until P5.7. Dashboard groups at most 200; totals are complete across the selected period. No paid endpoint contacted in CI. Offline benchmark must assert one cost basis per inference and zero assumed API fees. No production signoff.
