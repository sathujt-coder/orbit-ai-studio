The Studio acceptance job downloads the engineering artifacts produced by the current CI run. A new fail-closed validator verifies 15 exact raw JSON hashes against producer outputs, schema and commit/run/attempt identity. Eight defect stages plus final regression form a nine-artifact chain; all six regression artifacts remain independently bound. Eight existing cross-artifact edges are checked against downloaded bytes. The final retest inventory, 11 checkpoint verdicts, 27 receipt hashes/previous links, two occurrences, current closure execution and concurrent REOPEN audit are revalidated; the detailed trusted Docker validator remains mandatory.

The final artifact is engineering-final-defect-evidence.json. Studio requires its digest, schema, identity, retest and regression links as well as every previous gate. Twelve negative/positive regression tests exercise the final validator (synthetic envelopes, not real execution). The existing actual Docker lifecycle remains the authoritative execution evidence. System acceptance is development-only; no model qualification, release, merge, dispatch or execution authorization is granted. No new phase is declared until a roadmap decision.
