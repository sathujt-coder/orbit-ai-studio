# P5.1 — Reverse proxy foundation

This is a separate localhost-only demo stack (port 9443). Do not combine it with the direct TLS compose stack. Browser → NGINX TLS → verified native TLS upstream. The upstream service has no published port, uses an internal Docker network, and demo mode; this intentionally has no external model access. NGINX runs as UID 101 with read-only root, dropped capabilities and resource limits. Upstream validates the fixed Host and actual Origin. The proxy removes client-supplied forwarding headers and does not grant identity based on them.

The gateway limits login requests per observed connection IP (5/min, burst 4), general requests (20/sec, burst 40), connections (16), body size (30 KiB) and timeouts. Existing backend global failed-login throttle remains. These limits are not distributed or production DDoS protection; behind NAT clients may share a limit. Proxy access log excludes URLs, body, auth headers and query strings.

Prepare separate edge and upstream certificates/key pairs under deployment/proxy-tls/edge and upstream; upstream cert must be valid for localhost, trust anchor in deployment/proxy-tls/trust/upstream.pem. Private keys readable only by respective container UIDs (101 and 10001); use CA-issued certificates for a real environment. Start: docker compose -f deployment/compose.proxy.yml up -d --build. Visit https://localhost:9443 using a trusted certificate. Provision accounts through docker compose exec orbit with the local admin CLI. For rotation, install replacement cert files and trust anchor, validate and reload NGINX via sh deployment/reload_proxy.sh; restart backend if its certificate changed, verify health. No automatic issuance or ACME renewal, no external staging, no public ingress, no real-model calls. Image tags currently mutable; pin and audit before deployment. CI generates short-lived test certs only, checks actual TLS verification, hidden upstream port, login, CSRF, rate limit and reload. AI quotas, usage reporting, monitoring, load and real-world security review remain outstanding.
