# P5.1 — TLS container deployment foundation
Native TLS 1.2+, exact HTTPS origin and host, __Host- cookie (Secure/HttpOnly/SameSite=Strict, no Domain), HTTP local mode retained. Non-loopback binding requires all TLS configuration and explicit ORBIT_ALLOW_TLS_BIND=1. No trust in forwarded headers. Container runs as UID 10001, read-only root filesystem, named data volume, dropped capabilities and CPU/memory/PID limits. Compose publishes only 127.0.0.1:8443, demo mode, not publicly exposed. Use a real trusted certificate for actual staging; CI uses an ephemeral self-signed cert and explicitly trusts it, never disables verification.
Local: prepare deployment/tls/cert.pem and key.pem readable by container UID 10001 (protect private key); docker compose -f deployment/compose.yml up -d --build. Use https://localhost:8443 only. Provision real account interactively with docker compose -f deployment/compose.yml exec orbit python tools/create_auth_user.py --db /data/company.sqlite --user admin. Configure provider secrets separately, do not expose credentials. Native TLS is not a reverse proxy or production-grade WSGI server; public ingress, proxy trust design, DDoS protection, rate limiting, token budgets, load testing, external monitoring, backup policy, certificate renewal, image digest pinning and full security review remain outstanding. Do not deploy publicly. No model inference or production deployment in CI.
